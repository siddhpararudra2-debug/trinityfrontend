# Vesper.ai TypeScript clone

The HTML and CSS are copied from the supplied page without palette or animation changes. The interaction logic lives in `chatbot.ui.ts`.

## Build and view

1. Compile the TypeScript with `npx tsc -p tsconfig.json`.
2. Serve this folder with a local web server, then open `chatbot.ui.html` from that server. For example, run `python -m http.server 8000` in this folder and open `http://localhost:8000/chatbot.ui.html`.
